# Duudlaga Lite
Монгол яриаг текст болгон курсор байгаа газар шууд шивэх хэрэгсэл.

## Ашиглах заавар
1. `python main.py` командыг ажиллуулна.
2. Текст бичих талбараа (Notepad, Word, Browser г.м) сонгоод курсороо байрлуулна.
3. Гар дээрх **R** товчийг дараад ярьж эхэлнэ.
4. Таны ярьсан зүйл автоматаар шивэгдэх болно.

## Суулгах
```bash
pip install SpeechRecognition pynput PyAudio
```
